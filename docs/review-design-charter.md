## major

- **M-1** `docs/design-audit.md` — 헌장 §3은 `blur`/`glass`를 예외 없이 금지하는데, 감사 문서가
  "장식면 한정"이라는 헌장에 없는 예외를 만들어 `backdrop-filter`를 존치시켰다.
  → 고정 상단바·모달 백드롭·sticky 툴바의 blur를 제거하고 불투명 표면색으로 가독성을 확보할 것.
  헌장에 없는 예외를 만들려면 헌장을 먼저 고쳐야 한다.
  (같은 지적이 사이클3 리뷰에도 M-8로 독립 발견됐다.)

- **M-2** `smstudy/assets/css/style.css` — `.sm-section` 규칙을 `.sm-note-body` 직계 자식으로
  좁히면서, 같은 클래스를 쓰는 학습 기록의 중단원 현황·오답 노트가 padding과 구분선을 잃었다.
  감사 문서의 "학습 기록은 건드리지 않았다"는 기록과 실제 결과가 다르다.
  → 학습 기록 전용 섹션 규칙으로 기존 간격과 구분선을 보존할 것.

- **M-3** `smstudy/assets/js/app.js` — 빠른 복습의 독립 `section` 3개와 제목을 익명 `div`·`strong`으로
  바꿔 카드 수는 줄었으나 기능별 heading/region 의미 구조와 스크린리더 탐색점이 사라졌다.
  → 카드 통합이라는 시각 목표는 유지하되 이름 있는 하위 `section` 또는 의미 있는 제목 구조를 되살릴 것.
