# 사이클4 재설계 — 헌장 계측 검증

`docs/review.md`가 "이 세션은 백그라운드라 스크린샷을 찍지 못했다 / 슬롭 여부는 사람이
`docs/_snapshots/`를 열어 확인해야 한다"고 남긴 공백 중, **계측으로 판정 가능한 부분**을 닫는다.

## 방법

정적 서버 위에서 스냅샷 5종을 `iframe` 폭 320/768/1280으로 고정해 실제 레이아웃 엔진에서 쟀다.
계측 전 `innerWidth`가 0이 아님을 확인했다 — 0이면 컨테이너 쿼리가 폴백으로 넘어가
SVG가 `display:none`이 되고, 그 상태의 계측은 "이탈 0"이 공허하게 참이 된다.

## 결과 — 5화면 × 3폭 = 15조합 전부 통과

| 검사 | 결과 |
|---|---|
| 어절 쪼개짐 (한 어절이 두 줄에 걸침, Range 실측) | **0건** |
| 유채색 전경 종수 | **1종** (`rgb(41,151,255)` = accent) — 전 화면·전 폭 동일 |
| 그라디언트 / `box-shadow` / `backdrop-filter` | **0 / 0 / 0** |
| 문장인데 22px 이상 조판 | **0건** |
| 제목 위계 건너뜀 | **0건** |
| 가로 넘침 (`scrollWidth > viewport`) | **0건** |
| 뷰포트 밖 이탈 요소 (클리핑 조상 제외) | **0건** |
| SVG 겹침 — 텍스트×텍스트, 텍스트×도형(부분겹침) | **0건** |

대상: `landing`, `wordmaster`, `admin`, `diagrams`, `concept-sample`.

## 확인했으나 결함이 아니었던 것 2건

- **`diagrams` 320px에서 SVG 3개가 숨는다.** 폴백이 비어 있는지 확인한 결과, 번호 매긴
  범례 `<ol class="sm-d-legend">`(221px)가 대신 렌더되고 항목 텍스트도 온전했다.
  좁은 폭에서 도형을 접고 목록으로 내리는 의도된 반응형 동작이다.
- **랜딩의 `.icon-link` SVG 2개가 `visibility: hidden`이다.** 조상 체인을 따라가니
  닫힌 모바일 드로어(`.drawer`) 안의 사본이었고, 같은 소셜 링크가 `.list-row-nav`(678×64)로
  정상 노출된다. 드로어가 닫힌 상태의 정상 값이다.

## 여전히 닫히지 않은 것

**시각 취향 판정(슬롭 여부)은 못 했다.** 이 환경도 브라우저 pane이 표시되지 않아
스크린샷 합성이 되지 않는다(`Screenshot timed out: the Browser pane is not displayed`).
계측은 "틀림"만 잡고 "촌스러움"은 못 잡으므로, `docs/_snapshots/`의 5개 파일을
사람이 직접 열어 레퍼런스와 나란히 대조해야 한다. 이 항목은 열린 채로 남긴다.
