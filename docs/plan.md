## 1. 요청과 해석

> "걍 사이트 갈아엎어라. 기존 **기능**만 유지하면서 모든 사이트 형태를 최적의 형태로 바꿔라.
> 못봐주겠다." + 참고 규칙 4가지(무조건이 아니라 최대한 참고).

**해석**: 기능·데이터·라우팅은 그대로 두고 **시각 계층 전부를 다시 만든다.** 직전 사이클에서
개념 파트의 조판을 고쳤지만 사용자는 여전히 못 보겠다고 했다. 부분 수정으로는 안 되며
**디자인 시스템 자체를 다시 세우는 것**이 이번 범위다.

**직전 사이클에서 얻은 교훈 하나를 뒤집는다.** 나는 "아이콘은 의미를 더할 때만"이라며 아이콘을
41개에서 2개로 줄였고, 그 직후 사용자가 "이모지 위주의 디자인 선호"라고 했다.
→ **금욕적으로 덜어내는 것이 곧 좋은 디자인이 아니다.** 밋밋함도 실패다.

## 2. 시각 방향 (이번 사이클의 계약)

`docs/DESIGN.md`를 이 방향으로 개정한다. 개정본이 구현·리뷰의 상위 계약이다.

### 2.1 레퍼런스
| 화면 | 레퍼런스 | 어법 |
|---|---|---|
| 랜딩 | apple.com 다크 제품 페이지 | 큰 여백, 짧은 헤드라인, 절제된 강조, 스크롤 리듬 |
| 학습(smstudy 개념·WordMaster) | **iOS 설정/건강 앱의 그룹 리스트 + 카드** | 높은 밀도, 둥근 그룹 컨테이너, 행 단위 위계 |
| 조작(시험·기록·admin) | macOS 앱 (HIG) | 툴바·사이드바·표·시트 |

"문제집 조판"에서 **애플 시스템 UI**로 레퍼런스를 옮긴다. 사용자가 명시한 선호이며,
그룹 리스트는 밀도와 정돈을 동시에 준다.

### 2.2 색 — 진짜 다크
- 배경은 순검정에 가깝게(`#000`~`#0b0b0d`). 표면은 명도 단차로만 띄운다(보더 남발 금지).
- **강조색 1색.** 상태색은 상태에만.
- 금지: 억지 그라디언트, 유리 효과, 무지개 보더, 어설픈 드롭섀도.
  깊이는 **명도 단차와 1px 헤어라인**으로 만든다(애플 방식).

### 2.3 타이포
- 스택: `-apple-system, BlinkMacSystemFont, "Pretendard Variable", Pretendard,
  "Apple SD Gothic Neo", system-ui, sans-serif`. 웹폰트를 새로 불러오지 않는다(성능·CSP).
- 디스플레이/타이틀은 **음수 자간**, 본문은 0. 한국어 컨테이너 `word-break: keep-all` 필수.
- **글 양과 크기는 반비례.** 30자 넘는 문장을 타이틀급으로 조판하지 않는다.

### 2.4 이모지 (사용자 명시 선호)
- **식별자·구획 표지로 쓴다.** 단원·섹션·상태마다 고정된 이모지 1개.
  같은 대상은 사이트 어디서나 같은 이모지.
- 광학 크기를 일정하게(전용 클래스로 크기·정렬 고정). 문장 안에 흩뿌리지 않는다.
- 장식 남발 금지선: **한 행에 이모지 1개**, 의미 없는 자리에는 넣지 않는다.

### 2.5 밀도 — "미감과 컴팩트함을 동시에"
- 세로 리듬을 줄인다. 카드 하나에 문장 하나씩 두는 조판을 없애고 **그룹 리스트 행**으로 합친다.
- 한 화면에서 스크롤 없이 보이는 정보량을 직전 대비 늘리는 것이 목표다.
- 서술문을 **명제**로 줄인다. 문장이 아니라 판정 기준을 적는다.

### 2.6 다이어그램
직전 사이클의 결론(**CSS 조판, 손계산 SVG 금지**)을 유지한다. 겹침이 원리적으로 불가능하다.

## 3. 범위 — 무엇을 바꾸고 무엇을 안 바꾸나

**바꾼다**: 모든 CSS, 모든 화면의 마크업 구조와 렌더러의 조판 부분, 이모지 체계, 카피의 길이.

**바꾸지 않는다 (기능 보존 계약)**:
- 라우팅·상태·이벤트 핸들러의 **동작**, `localStorage` 키, API 경로, Worker 계약
- 데이터 스키마(`notebook-data.js`·`data.js`·WordMaster 데이터)의 **필드**
- 로그인 게이팅 정책(미로그인 방문자에게 학습 내용 비노출)
- 인쇄 팔레트 경로, 이미지 폴백 동작
- `escapeHtml()` 정책 — 데이터 문자열은 예외 없이 이스케이프
